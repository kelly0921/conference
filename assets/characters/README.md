# Kelly character artwork

`kelly-hi.png` is an unchanged copy of the user-supplied `17-hi.png` in `C:/Users/kelly/Downloads/Kelly Icons`. It is a 512 × 512 RGBA PNG with an opaque cream background. No AI generation, background removal or redrawing was used.

The header displays it at 44 × 44 px as the product’s home icon, and the browser tab uses matching PNG/ICO assets. It is not displayed in the preparation panel. `scripts/prepare_brand.py` only resizes and encodes the artwork for these uses; it does not crop, redraw or change the background. It is not an avatar for a fictional example or a checklist status. Other supplied characters remain in their original folder until a specific context calls for them.
